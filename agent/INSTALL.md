# Установка и запуск

## Что внутри

- SKILL.md — описание навыка для GigaCowork.
- SYSTEM_PROMPT.txt — системный промпт агента.
- scripts/ — Python-скрипты навыка (stdlib + openpyxl + xlrd).
- references/ — справочники и шаблон формы Cloud.

## Требования

- Python 3.10+.
- Пакеты: openpyxl, xlrd.

Установка пакетов:

    pip install openpyxl xlrd

В Ubuntu/Debian без pip:

    sudo apt install python3-openpyxl python3-xlrd

## Запуск

1. Положи три файла Excel в любую папку (например, data/):
   - выгрузка ФУЛ из 1С;
   - реестр Cloud;
   - сотрудники из 1С.

2. Запусти:

    python3 scripts/distribute.py --ful data/ful_1c.xlsx --cloud data/cloud_registry.xlsx --employees data/employees_1c.xlsx --out runs/output.xlsx

3. Результат — xlsx с 5 листами:
   - «Новые строки Cloud»
   - «Повторные отправки»
   - «Возможные пропуски»
   - «Требует внимания»
   - «Журнал решений»

4. В консоли появится короткий отчёт:

    Новых строк: N
    Повторных отправок: M
    Возможных пропусков: K
    Требует внимания: T
    Файл результата: <путь>

## Запуск в GigaCowork

1. Загрузи содержимое папки agent/ как навык (SKILL.md в корне навыка).
2. Проверь, что скрипты лежат в scripts/ и шаблон в references/.
3. Приложи три файла и запусти агента без текста запроса.
4. Агент запустит скрипт и вернёт отчёт и файл результата.

## Что важно

- Колонки во входных файлах ищутся по заголовкам, не по номеру.
- Лишние колонки и другой порядок колонок не мешают.
- Имя листа в каждом файле не важно — читается первый лист.
- Сеть и внешние сервисы не используются.
