# Навык: распределение заказов между логистами

## Когда применять

Пользователь прикладывает три файла Excel и запускает агента без текста
запроса (или с пустым сообщением). Файлы:

1. Выгрузка ФУЛ из 1С (по строке на упаковочный лист).
2. Реестр Cloud (история заказов).
3. Сотрудники из 1С (ФИО, состояние, должность, табельный номер).

Если какого-то файла нет — не запускай скрипт, сообщи пользователю,
какого файла не хватает. Не подставляй ничего от себя.

## Что делает навык

Детерминированный скрипт scripts/distribute.py:

- читает три xlsx, колонки ищет по заголовкам, не по номеру;
- отделяет новые ФУЛ от повторных отправок и дублей внутри пачки;
- определяет группу логистов: air -> авиа; не-air + Китай -> ВЭД;
  не-air + не Китай -> мультимодальные;
- исключает сотрудников в отпуске, уволенных, ассистентов и руководителей;
- выбирает логиста: чаще всех работал с поставщиком, иначе наименее
  загруженного в группе; один поставщик в пачке — один логист;
- формирует xlsx с 5 листами: «Новые строки Cloud», «Повторные отправки»,
  «Возможные пропуски», «Требует внимания», «Журнал решений»;
- где данных нет — пишет «не определено», правдоподобные значения
  не подставляет.

Решение о группе и логисте принимает только скрипт. Модель не решает,
кого назначить, — она запускает скрипт и пересказывает результат.

## Как запустить

1. Определи пути к трём приложенным файлам (пользователь приложил их
   в чат). Если файлы лежат в рабочей папке — используй их имена.
2. Запусти скрипт:

   python3 scripts/distribute.py --ful <путь_к_ФУЛ.xlsx> --cloud <путь_к_Cloud.xlsx> --employees <путь_к_сотрудникам.xlsx> --out <папка_результата>/result.xlsx

   Если папка результата не задана — сохрани в текущую под именем
   result.xlsx.
3. Дождись завершения. Скрипт печатает короткий отчёт:

   Новых строк: N
   Повторных отправок: M
   Возможных пропусков: K
   Требует внимания: T
   Файл результата: <путь>

4. Не редактируй результат. Не подставляй свои значения.

## Как ответить пользователю

Коротко, по шаблону:

Готово.
Новых строк: N
Повторных отправок: M
Возможных пропусков: K
Требует внимания: T

Файл результата: <путь>

Если скрипт упал с ошибкой — приведи текст ошибки как есть, не
переформулируй. Если какой-то колонки во входных файлах не нашлось,
скрипт сообщает об этом в консоли — перескажи это пользователю.

## Ограничения

- Только приложенные файлы. Никакой сети, коннекторов, интеграций с 1С
  или Cloud.
- В Cloud и 1С ничего не записывается. Результат — только xlsx.
- Если в группе нет доступных логистов — заказ остаётся без логиста,
  в другую группу не передаётся.
- Если номер заказа, страна или способ доставки не определены — строка
  идёт в «Требует внимания», а не в новые строки Cloud.
