# order-distribution-agent

AI-агент для распределения новых заказов поставщиков между логистами
и подготовки строк реестра Cloud строго по его форме.

Тестовое задание: разработка AI-агентов на GigaCowork (Сбер, «Салют для Бизнеса»).

## Что делает агент

На вход — три выгрузки Excel:

1. Выгрузка ФУЛ из 1С (по строке на упаковочный лист).
2. Реестр Cloud (история заказов).
3. Сотрудники из 1С (ФИО, состояние, должность, таб. №).

На выход — один Excel-файл с листами:

- `Новые строки Cloud` — 12 колонок в порядке реестра;
- `Повторные отправки` — с комментарием «Повторная отправка ФУЛа, [дата]»;
- `Возможные пропуски` — ФУЛ раньше последней записи Cloud, которых нет в реестре;
- `Требует внимания` — заказы без логиста / с неполными данными и причина;
- `Журнал решений` — по каждому ФУЛ: статус, группа, логист, основание.

Плюс короткий ответ в чат по шаблону.

## Ключевые принципы

- Решение о группе и логисте принимает **детерминированный скрипт**, не модель.
- Колонки во входных файлах ищутся **по заголовкам**, не по номеру.
- Где данных нет — пишется **«не определено»**, правдоподобные значения не подставляются.
- Только приложенные файлы, без сети, коннекторов и внешних интеграций.
- Python 3, только стандартная библиотека + openpyxl и xlrd.

## Запуск (упрощённый режим, без GigaChat API)

Установить зависимости:

    pip install openpyxl xlrd

Запустить скрипт:

    python3 agent/scripts/distribute.py --ful data/ful_1c.xlsx --cloud data/cloud_registry.xlsx --employees data/employees_1c.xlsx --out runs/output.xlsx

Скрипт печатает короткий ответ в чат и сохраняет Excel.
В GigaCowork тот же скрипт запускается навыком; модель пересказывает вывод.
